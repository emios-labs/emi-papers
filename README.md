# Emi — Papers

Public artifact repository for the mathematics papers produced by the Emi research
program. Each paper ships with its complete proof objects: certificate tables, exact
rational coefficient data, generator scripts, independent checkers, and a full
SHA-256 manifest, so every computer-assisted step can be verified from what this
repository contains.

## Papers

### [defect-chains/](defect-chains/) — The 1/3–2/3 conjecture for posets of defect ≤ 3
The **Three-Defect Chain Theorem**: every finite non-chain poset that becomes a chain
after deleting at most three elements has an incomparable pair {u,v} with
1/3 ≤ Pr(u≺v) ≤ 2/3, where the probability is over uniformly random linear extensions.
Together with the companion defect-two paper (including the equality-rigidity
classification extending Aigner's width-two theorem). See the directory README for the
artifact-to-theorem map and one-command verification.

## Versioning

Tagged releases correspond to exact paper versions; the mutable branch may move ahead
of the last tag. Cite the release tag (and, when available, the archived DOI), not the
branch.
